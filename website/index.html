Installation

⊞ Windows

Installer herunterladen und ausführen — Galaxy Launcher richtet sich selbst ein.

⊞ Installer herunterladen .exe · GitHub Releases

🐧 Linux

Direkt im Terminal — die Befehle holen sich automatisch die jeweils neueste Version.

curl -sL $(curl -s https://api.github.com/repos/Mrdudidj/galaxy-launcher/releases/latest | grep "browser_download_url.*AppImage" | cut -d '"' -f 4) -o GalaxyLauncher.AppImage
chmod +x GalaxyLauncher.AppImage
./GalaxyLauncher.AppImage
curl -sL $(curl -s https://api.github.com/repos/Mrdudidj/galaxy-launcher/releases/latest | grep "browser_download_url.*deb" | cut -d '"' -f 4) -o galaxy-launcher.deb
sudo dpkg -i galaxy-launcher.deb

Häufige Fragen

Kostet Galaxy Launcher etwas?

Nein. Komplett kostenlos und quelloffen — keine Bezahlfunktionen auf dieser Webseite.

Welche Betriebssysteme werden unterstützt?

Windows und Linux, jeweils mit einem eigenen echten Installationsweg (siehe oben).

Brauche ich einen Microsoft-Account?

Zum Spielen ja, wie bei jedem anderen Minecraft-Launcher — das Anmelden ist der einzige Account, den Galaxy Launcher braucht.

Wo melde ich Bugs oder Ideen?

Direkt im GitHub-Repository — Issues und Pull Requests sind willkommen.

Systemanforderungen

Galaxy Launcher selbst ist bewusst schlank gehalten — die eigentliche Anforderung kommt von Minecraft: Java Edition selbst.

Minimum

  • Windows 10/11 oder eine aktuelle Linux-Distribution
  • 4 GB RAM
  • Grafikkarte mit OpenGL-4.x-Unterstützung

Empfohlen

  • 8 GB RAM oder mehr
  • Dedizierte Grafikkarte
  • SSD für schnelle Instanz-Downloads
